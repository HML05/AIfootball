# 数据来源与采集说明

> 足球数据分析与 AI 预测系统 ｜ 整理日期：2026-09-10

## 一、总体思路

系统采用**"免费源为主干、付费源做增强"**的多源架构：日常运行（赛程、赛果、积分榜、实时比分）全部由免费数据源支撑；付费源（球小策）仅用于免费源确实拿不到的字段（完整阵容、转会）。

**合规原则**：预测模型**只使用纯足球事实数据**（比分、射门、角球、红黄牌、阵容等），**不采集、不使用任何博彩赔率、盘口或市场资金数据**，保证模型的"纯净性"与学术中立性。

## 五、已知数据缺口及原因（如实记录）

| 缺口 | 现状 | 原因 |

## 六、数据质量处理

1. **队名规范化**：跨源队名差异（`Sevilla FC` / `Sevilla`、`Barça` / `Barcelona`、`Man City` / `Manchester City`）通过"别名表 + 去俱乐部词 + 归一化 + 全局匹配"统一到库内规范名，并清理孤儿球队；
2. **幂等入库**：所有入库操作以（联赛 + 日期 + 主客队）为键做 upsert，重复运行不产生脏数据；
3. **限速与去重**：球小策 30 次/分钟限速 + 60 秒同请求本地缓存（不扣点）；Football-Data.org 请求间隔 7 秒以规避 10 次/分钟限制；
4. **配额门控**：实时比分轮询仅在"有今日比赛或进行中比赛"时才发起请求，无比赛日零消耗。
