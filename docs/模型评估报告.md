# 模型评估报告（可复现）

> 足球数据分析与 AI 预测系统 · 三分类（主胜/平局/客胜）
> 模型族：XGBoost（v1–v9）+ 深度学习分支（MLP / 序列 GRU）
> 评估日期：2026-09-12 ｜ 数据源：football-data.org + football-data.co.uk + Understat + Transfermarkt

## 一、评估协议（关键）

足球预测最容易犯的错误是**数据泄漏**。本报告采用严格的 **walk-forward（步进式样本外）** 评估：

- **训练集**：`< 2025-08-01` 的比赛（6,534 场）
- **测试集**：`2025-08-15 ~ 2026-09-03` 的比赛（**1,817 场**，完全不参与训练）
- 特征计算**逐场递推**：Elo 只用该场之前的结果更新；所有球队统计使用 `shift(1)` / 累计窗口，绝不含当场与未来数据
- 对照基线：**全押主胜**（准确率 44.36%）

> ⚠️ 早期版本曾对"整个 2526 赛季"回测得到 53.5%，但该赛季部分比赛在模型训练集内，属于**虚高**。本报告的所有数字均来自上述样本外协议。

复现命令：

```bash
python scripts/walkforward_compare.py --cutoff 2025-08-01     # 四种方案对比
python scripts/walkforward_eval.py --cutoff 2025-08-01        # 单模型详细指标
```

## 二、方案对比（同一测试集 1,817 场）

| 方案 | 特征数 | 准确率 | 宏平均 F1 | LogLoss | 平局召回 | vs 基线 |
|---|---|---|---|---|---|---|
| v1 基线（Elo + 状态 + 攻防） | 31 | 47.00% | 0.3889 | 1.0805 | 5.5% | +2.64pp |
| **v2 新特征** | 90 | **50.03%** | 0.4007 | 1.0525 | 3.5% | **+5.67pp** |
| v3 = v2 + 代理 xG | 110 | 48.16% | 0.3865 | 1.0440 | 3.3% | +3.80pp |
| v4 = v2 + TM 身价/伤病 | 97 | 48.82% | 0.3834 | 1.0508 | 2.0% | +4.46pp |
| v5 = v2 + 代理 xG + TM | 117 | 49.09% | 0.3893 | 1.0477 | 2.6% | +4.73pp |
| v6 = v2 + **官方 xG**(Understat) | 119 | 48.10% | 0.3925 | 1.0391 | 4.6% | +3.74pp |
| **v7 = v2 + 官方 xG + TM** | 126 | 49.70% | 0.3985 | **1.0292** | 3.5% | +5.34pp |
| v8 = v2 + 官方 xG + 权重 + 平局阈值 | 119 | 44.03% | **0.4263** | 1.0449 | **30.9%** | −0.33pp |
| **v9 = 集成 v2 + v7（等权概率平均）** | 90+126 | **50.14%** | 0.3985 | 1.0338 | 2.8% | **+5.78pp** |
| v2 + 类别权重 | 90 | 46.89% | 0.3966 | 1.0652 | 7.4% | +2.53pp |
| v2 + 权重 + 平局阈值（CV 选出 τ=0.36） | 90 | 46.67% | 0.4062 | 1.0652 | 10.5% | +2.31pp |

**结论：**

1. **特征工程收益最大**：把原本未使用的数据（射门、射正、角球、红黄牌、休息天数、7 天赛程密度、历史交锋、联赛标识）做成特征后，准确率 **47.00% → 50.03%（+3.03pp）**，LogLoss 从 1.0805 降到 1.0525，宏 F1 同步提升；
2. **真实 xG（Understat，覆盖五大联赛 99.9%）比代理 xG 更有价值**：v6/v7 的 LogLoss 分别达到 1.0391 / **1.0292**，优于代理 xG 方案（v3/v5 = 1.0440/1.0477）；其中 **v7 是单模型最优 LogLoss**。但 xG 类特征**不提升硬判准确率**（48.1%–49.7% < v2 的 50.03%），说明射门类统计 + Elo 已经覆盖了大部分"机会质量"信息；
3. **集成是最优组合**：v2 与 v7 等权概率平均后 **准确率 50.14%（最高）且 LogLoss 1.0338（次优，明显优于 v2 的 1.0525）** —— 两个模型互补（v2 偏"结果导向"，v7 偏"过程质量"），代价只是推理时要跑两个模型；
4. **官方 xG 显著改善平局识别**：v8（官方 xG + 类别权重 + 阈值调优）把**平局召回从 10.5% 提升到 30.9%、宏 F1 从 0.4062 提升到 0.4263（均为历史最高）**，代价是准确率降至 44.03%；
5. **现实上限**：即便完成上述所有优化，样本外准确率约 **50%**，仅高出"全押主胜"基线约 **5.7pp**——这与足球低得分、高偶然性的客观规律一致，也说明任何"命中率 60%+"的宣传都应被质疑。

**部署选择（线上已采用 v9 集成）**

| 场景 | 推荐模型 | 理由 |
|---|---|---|
| **默认（当前线上）** | **v9 集成 v2+v7** | 准确率最高 50.14%，且概率校准明显更好（LogLoss 1.0338） |
| 只看命中率且要最简 | v2 | 50.03%，单模型、推理最快 |
| 需要高质量概率（风险/期望计算） | v7 | LogLoss 最低 1.0292 |
| 需要识别平局（宏 F1 优先） | v8 | 平局召回 30.9%、宏 F1 0.4263 |

## 四、代理 xG 的构建与验证（数据工程创新点）

**背景**：官方 xG（预期进球）数据在免费源中缺失（库内仅 107 场有 xG，占 0.9%），而全量购买历史 xG 成本约 ¥530，不具备可行性。

**方案**：利用库内已有的 **9,026 场射门类统计**（射门、射正、角球、犯规、红黄牌），用 **泊松回归** 拟合"射门统计 → 进球数"，得到每支球队每场比赛的**期望进球代理值**：

```
λ(进球) = exp(β0 + β1·射门 + β2·射正 + β3·角球 + β4·犯规 + β5·牌
               + β6·对手射门 + β7·对手射正 + β8·主场 + β9·联赛)
```

拟合结果（18,012 条"球队-比赛"样本）：

| 项目 | 数值 |
|---|---|
| 验证集 MAE | **0.7358**（均值基线 0.9669，降低 24%） |
| 射正系数 | +0.2060（主要信号） |
| 主场系数 | +0.0841 |
| 与官方 xG 相关性（99 场） | 主队 **0.627** / 客队 **0.542** |
| 覆盖 | **9,007 场**（vs 官方 xG 的 107 场） |

**诚实结论**：代理 xG 覆盖度是官方数据的 84 倍，但**精度有限**（与官方相关性约 0.6）；接入模型后 **LogLoss 改善（1.0525→1.0456）、平局召回提升（3.5%→4.8%），但准确率下降（50.03%→48.43%）**。因此：

- **准确率优先** → 线上使用 v2；
- **概率质量优先**（如做概率型输出/期望值分析）→ 使用 v3。

复现命令：`python scripts/build_proxy_xg.py`、`python scripts/walkforward_compare.py`

## 六、深度学习分支（表格 MLP 与序列 GRU）

代码：`src/prediction/dl_features.py`（序列特征）、`src/prediction/dl_model.py`（两个网络）、
`scripts/train_dl.py`（主实验）、`scripts/dl_robustness.py`（稳健性 + 泄漏检验）。
结果文件：`models/dl_report.json`（单切点）、`models/dl_robustness.json`（三切点）。

### 6.1 结构

| 模型 | 输入 | 说明 |
|---|---|---|
| **MatchMLP** | 126 维表格特征 | 与 XGB-v7 **完全相同**的特征集，仅换模型族（对照实验，排除特征差异） |
| **MatchGRUNet** | 126 维表格 + 每队近 10 场 × 12 维序列 | 主客队**共享参数的 GRU 孪生编码器**，只用该场比赛之前的比赛（deque 快照，严格防未来信息） |

### 6.2 多切点稳健性（回答"是不是运气"）

同一套特征、同一套代码，只换时间切点各跑一遍（3 个随机种子取概率平均）：

| 方案 | 2024-08-01 | 2025-02-01 | 2025-08-01 | **均值** | 跨切点极差 |
|---|---|---|---|---|---|
| XGB-v2 | 49.59% | 44.74% | 50.03% | 48.12% | **5.29pp** |
| XGB-v7 | 50.47% | 48.48% | 49.70% | 49.55% | 1.99pp |
| **DL-MLP** | **52.84%** | **52.61%** | **52.12%** | **52.52%** | **0.72pp** |
| **DL-GRU** | **52.89%** | 51.95% | 51.51% | **52.12%** | 1.38pp |
| 集成 XGB-v2+v7（v9） | 50.32% | 47.19% | 50.14% | 49.22% | 3.13pp |
| 集成 XGB-v7+DL-GRU | 51.77% | 51.09% | 51.68% | 51.51% | 0.68pp |
| *基线（全押主胜）* | *43.43%* | *43.41%* | *44.36%* | — | — |

**要点**：
1. **DL 在 3 个切点上全部领先**，均值 +3.0pp（对最强 XGB-v7）到 +4.4pp（对 XGB-v2）；
2. **DL 的稳定性显著更好**：跨切点极差 0.72pp，而 XGB-v2 达 5.29pp（在 2025-02 切点 XGB-v2 仅 44.74%，几乎贴住基线 43.41%）；
3. 单切点报告（5 种子平均）：DL-MLP 51.90%、DL-GRU 51.24%、集成 XGB-v7+GRU 51.57%，与上表同切点结果一致。

### 6.3 配对显著性检验（McNemar）

对**同一批测试比赛**做配对比较（比"两个准确率谁高"更严格）：

| 切点 | 对比 | 仅前者对 | 仅后者对 | p 值 | 结论 |
|---|---|---|---|---|---|
| 2024-08-01 | DL-MLP vs XGB-v2 | 370 | 255 | <0.001 | 显著 |
| 2024-08-01 | DL-GRU vs XGB-v2 | 351 | 234 | <0.001 | 显著 |
| 2025-02-01 | DL-MLP vs XGB-v2 | 429 | 227 | <0.001 | 显著 |
| 2025-02-01 | DL-GRU vs XGB-v2 | 395 | 210 | <0.001 | 显著 |
| 2025-08-01 | DL-MLP vs XGB-v2 | 176 | 138 | 0.037 | 显著 |
| 2025-08-01 | DL-MLP vs XGB-v7 | 162 | 118 | 0.010 | 显著 |
| 2025-08-01 | DL-GRU vs XGB-v2 | 156 | 129 | 0.123 | **不显著** |

9 组比较中 8 组显著；唯一不显著的是**最小测试集（1,817 场）上 GRU vs v2**——样本量不足，如实标注。

### 6.4 数据泄漏检验（标签置换）

把**训练集标签随机打乱**后重新训练 MLP，再在测试集上评估：

| 指标 | 打乱标签后 | 应达到 | 结论 |
|---|---|---|---|
| 准确率 | **44.36%** | ≈ 基线 44.36% | ✅ 完全退化到基线 |
| LogLoss | **1.0742** | ≈ 随机 1.0986 | ✅ 接近随机 |

若管线里混入未来信息，打乱标签后仍会明显高于基线 —— 实测**精确落到基线**，说明
**特征构建（Elo 递推、shift(1)、序列 deque 快照）没有未来信息泄漏**。

### 6.5 诚实的限制（必须与结论一起说）

1. **DL 放弃平局换准确率**：平局召回仅 **0.1%–1.7%**（XGB-v2 为 3.5%–12.8%，极端如 GRU 单种子**一场平局都不预测**）；
2. **宏平均 F1 并未提升**：DL 0.385–0.400 vs XGB-v2 0.399–0.429 —— 即 DL 是"**准确率与概率质量更好，但类别均衡性更差**"，不是全面更优；
3. **融合无额外收益**：集成 XGB-v7+DL-GRU 均值 51.51%，**低于纯 DL-MLP 的 52.52%**，说明 XGB 分支没有带来互补信息；
4. **量级仍有限**：即便最优方案也只比基线高约 8pp，符合足球低得分、高偶然性的客观规律，任何"命中率 60%+"的说法都应被质疑。

python scripts/dl_robustness.py --seeds 3 --epochs 150   # 三切点 + McNemar + 泄漏检验(约 1.5 分钟)

## 七、局限与后续工作

1. **平局识别仍是短板**：DL 分支靠放弃平局换取准确率（召回 0.1%–1.7%），XGB 分支经权重/阈值调优后可达 30.9% 但准确率降至 44.03% —— 两者是**取舍关系**，尚无方案同时做好；
2. **概率质量与硬判准确率不一致**：官方 xG（v6/v7）显著改善 LogLoss（最低 1.0292）却不提升硬判准确率，说明"更好的概率"不等于"更高的命中率"；
3. **球员层面信息仍只用到阵容价值/伤病**：`tm_*` 已进入 v7 特征，但**逐场首发、位置、伤停是否出场**等尚未接入（依赖 API-Football 回填）；
4. **概念漂移**：DL 跨切点方差小、XGB 方差大，提示**按赛季重训**对 XGB 更关键；系统已支持定时任务 + 回测脚本；
5. **未做超参搜索**：DL 与 XGB 均使用手工调参，Optuna 类搜索可能还有 1–2pp 空间，但需警惕在 1,817 场测试集上过拟合。
