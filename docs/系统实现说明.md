# 系统实现说明

> 足球数据分析与 AI 预测系统 ｜ 整理日期：2026-09-10

本文说明系统的关键实现细节与运行手册，供论文"系统实现"章节与项目维护使用。

## 一、特征工程实现（核心）

### 1.1 无泄漏特征计算

足球预测最致命的错误是**数据泄漏**（用未来信息预测过去）。本系统通过两条硬约束杜绝：

| 约束 | 实现方式 |
|---|---|
| Elo 评级只用历史 | 按时间顺序逐场递推：每场比赛记录**赛前**的 Elo，赛后再更新（K=32，净胜球加权，主场优势 +65） |
| 球队统计只用历史 | 所有累计/滚动统计使用 `groupby(team).shift(1)` 后再 `cumsum/rolling`，确保不含当场与未来 |

### 1.2 特征集演进

| 版本 | 维度 | 内容 |
|---|---|---|
| v1 | 31 | Elo（5）、近期状态（12）、主客场（6）、交锋（4）、攻防效率（6）、联赛排名（3） |
| v2 | 90 | v1 + **射门/射正/角球/犯规/红黄牌**（近 5/10 场与累计）、**休息天数**、**7 天赛程密度**、**历史交锋（次数/胜率/场均进球）**、**联赛标识** |
| v3 | 106 | v2 + **代理 xG**（见第三节） |

模块：`src/prediction/vector_features.py`（v1）、`vector_features_v2.py`（v2/v3）。

### 1.3 训练/推理一致性保障

线上预测时**不单独实现一套特征代码**，而是把待预测比赛作为"占位行"（比分置 0、结果置 D）追加到历史数据末尾，用与训练完全相同的函数计算特征，再取占位行对应的特征向量：

```python
new_df, offset = append_dummy_fixtures(hist_df, fixtures)      # 追加占位行
X, y, dates, divs, leagues, ids = build_features_v2(new_df, return_ids=True)
Xd = X[ids >= offset]                                          # 取出占位行特征
proba = model.predict_proba(Xd)
```

由于占位行的特征只依赖其**之前**的比赛（shift(1) 与逐场 Elo），因此计算结果与真实比赛完全一致。

## 二、模型与评估实现

| 项目 | 实现 |
|---|---|
| 模型 | XGBoost 三分类（`multi:softprob`，300 棵树，depth=5，lr=0.05，L1/L2 正则） |
| 评估协议 | **walk-forward（步进式样本外）**：训练 `< 2025-08-01`（6,534 场），测试 `2025-08-15 ~ 2026-09-03`（1,817 场） |
| 对照基线 | 全押主胜（44.36%） |
| 指标 | 准确率、宏平均 F1、LogLoss、分类别召回、分联赛命中率 |
| 平局处理 | 类别权重（逆频率）+ 平局阈值（在训练集内用时间序列 CV 选出 τ=0.36） |
| 脚本 | `scripts/walkforward_eval.py`、`scripts/walkforward_compare.py` |

**主要结果**（详见《模型评估报告》）：

| 方案 | 准确率 | 宏F1 | LogLoss | 平局召回 |
|---|---|---|---|---|
| v1 基线 | 47.00% | 0.3889 | 1.0805 | 5.5% |
| **v2（线上）** | **50.03%** | 0.4007 | 1.0525 | 3.5% |
| v3（+代理 xG） | 48.43% | 0.3961 | **1.0456** | 4.8% |
| v2 + 权重 + 阈值 | 46.67% | **0.4062** | 1.0652 | **10.5%** |

## 三、代理 xG 实现（数据工程创新点）

**问题**：官方 xG 数据在免费源中缺失（库内仅 108 场），全量购买约需 ¥530。

**方案**：用库内已有的 9,026 场射门类统计，通过**泊松回归**拟合"射门统计 → 进球数"：

```
λ = exp(β0 + β1·射门 + β2·射正 + β3·角球 + β4·犯规 + β5·牌
        + β6·对手射门 + β7·对手射正 + β8·主场 + β9·联赛)
```

| 结果 | 数值 |
|---|---|
| 训练样本 | 18,012 条（球队-比赛） |
| 验证集 MAE | 0.7358（基线 0.9669，降低 24%） |
| 与官方 xG 相关性（99 场） | 主队 0.627 / 客队 0.542 |
| 覆盖 | 9,007 场（官方的 84 倍） |

**结论**：代理 xG 使 LogLoss 从 1.0525 降至 1.0456（概率质量最优）、平局召回从 3.5% 升至 4.8%，但准确率从 50.03% 降至 48.43%。因此线上以 v2 为主，v3 用于概率型输出场景。脚本：`scripts/build_proxy_xg.py`。

## 四、预测闭环实现

```
① 生成预测   predict_upcoming_v2(days)   → 写入 predictions（含概率、结果、特征快照）
② 赛后回填   backfill_results()           → 比赛 FT 后写入 actual_result 与 hit 标记
③ 复盘统计   review_stats()               → 总体/分联赛/分类型命中率 + 最近明细
④ 历史回测   predict_backtest(区间)        → 批量回测并存库（is_backtest=1）
```

自动化：`src/scheduler/tasks.py` 在每次赛程同步与比分轮询之后调用 `backfill_predictions()`，实现"比赛一结束，复盘自动更新"。

**幂等性**：`predictions` 表对 `match_id` 建唯一索引，重复预测覆盖而非累加。

## 五、数据采集的工程细节

| 细节 | 实现 |
|---|---|
| 幂等 upsert | 以（联赛 + 日期 + 主客队 id）为键，存在则更新比分/状态，否则插入 |
| 队名规范化 | 别名表（`SEARCH_ALIAS`/`_TEAM_ALIAS`）+ 去重音 + 去俱乐部词（FC/CF/SC…）+ 全局互相包含匹配 |
| 孤儿清理 | 同步后删除"既不属任何比赛也不属任何积分榜"的球队，避免昵称残留 |
| 限速与退避 | 球小策 2.1s/次 + 429 退避重试；Football-Data.org 7s/次（10 次/分钟限制） |
| 本地缓存去重 | 球小策 60 秒内同请求命中本地缓存，不扣点数 |
| 预算上限 | 所有付费脚本支持 `--budget`，达到上限自动停止；支持 `--dry-run` 预演 |
| 演示兜底 | 未配置 Token 时 `sync_fixtures.py` 自动切换为确定性演示赛程生成器 |

## 六、运行手册

### 6.1 环境准备

```bash
pip install -r requirements.txt
copy .env.example .env      # 填入各数据源 Token/Key
python scripts/init_data.py # 建库 + 历史数据 + Elo
```

### 6.2 日常运行（免费）

```bash
uvicorn src.main:app --host 0.0.0.0 --port 8000   # 后端(自动启动定时任务)
streamlit run frontend/app.py    --server.port 8501   # 用户端
streamlit run frontend/admin.py  --server.port 8502   # 管理端
```

### 6.3 数据与模型维护

```bash
python scripts/sync_fixtures.py --days 7        # 同步赛程
python scripts/extend_fixtures.py --days 30     # 扩展 30 天窗口
python scripts/sync_standings.py                # 积分榜 + 队徽
python scripts/predict_upcoming.py --days 7     # 生成预测
python scripts/review_predictions.py            # 回填 + 命中率报告
python scripts/walkforward_compare.py           # 严格样本外对比(论文用)
python scripts/build_proxy_xg.py                # 重建代理 xG
python scripts/check_matchpack_window.py        # 赛前包窗口提醒
```

### 6.4 常见问题

| 现象 | 处理 |
|---|---|
| 页面打不开（8502） | 确认 Streamlit 已启动；用 `127.0.0.1` 而非 `localhost`（IPv6 解析问题） |
| 赛程同步 400 | Football-Data.org 单次跨度 ≤10 天，改用 `extend_fixtures.py` 分窗口 |
| 积分榜旧赛季 403 | 免费档赛季深度限制，属预期 |
| 赛前包返回"基础快照" | 距开赛过远，用 `--max-hours-ahead 36` 在临近开赛时抓取 |
| 模型文件缺失 | 依次运行 `train_v2.py` 与 `build_proxy_xg.py` |
